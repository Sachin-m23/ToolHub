Equity Markets Tool Directory
This website brings together all the financial analysis tools I’ve built in one place. Instead of keeping track of separate links, you can come here to see everything I’ve created and quickly find the right tool for the job.

What you can do here:

See all my tools at a glance. Each tool has its own colour so they’re easy to tell apart.
Learn what each one does. Select a tool to read a short overview of what it’s for and what it produces.
Go straight to the tool. Click “Open full tool” to launch it in a new tab.

Tools currently included:

DCF Valuation: estimates what a company is worth based on the cash it’s expected to generate.
Comparable Company Analysis: compares a company against similar businesses to see if it looks cheap or expensive.
Portfolio Optimisation: helps you find the best mix of investments for the level of risk you’re comfortable with.
